# OBS-0004 — Does sweep depth predict reversion better than the binary rule?
Type: Observation Record. **NOT a Discovery Candidate.** Date 2026-07-22 · XAUUSD H1 · loader · 429 reject interactions (with ATR) · NRQ-2.

**Q:** Among prior-day-extreme rejects, does deeper ATR-normalized penetration (how far the wick pierced the level) predict stronger reversion than the binary close-inside classification?
**Pre-reg:** penetration=(high−PDH)/ATR14 (up) / (PDL−low)/ATR14 (down). Reversion ⇒ corr(penetration, continuation-excess) < 0 and deep tercile more negative.

**Result:** corr(penetration, continuation-excess) = −0.025 (K6), +0.039 (K12) — **≈0**. Shallow/mid/deep tercile means all near 0 with CIs spanning 0 (median penetration only 0.20 ATR; p90 0.72 ATR — sweeps are shallow). No monotonic depth ordering.

**Verdict: NEGATIVE.** Sweep depth carries no predictive content for reject aftermath; it does not rescue the sweep concept from OBS-0001/0002. NRQ-2 closed.
