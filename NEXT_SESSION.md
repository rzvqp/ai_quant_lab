# NEXT_SESSION.md — Common Orientation

**Split on 2026-07-20**, per explicit CEO decision, into two flow-specific operational documents. This
file is now intentionally short — it exists only to point you to the right one.

The project is separated into two independent, parallel development flows:

- **Flow A — Alpha Discovery Laboratory** (the 40-Edge Alpha Discovery Program) → go to
  **`NEXT_SESSION_FLOW_A.md`** for its current state, last commit, edges studied, results,
  limitations, next edge, and resume instructions.
- **Flow B — AI Trader Development** (the pre-existing main roadmap, currently on Strategy Health) →
  go to **`NEXT_SESSION_FLOW_B.md`** for its current state, last commit, the Strategy Health situation,
  the approved design and its remaining conditions, the next step, and resume instructions.

**Rules:**

- Operational session logs are no longer written directly into this file — they go into
  `NEXT_SESSION_FLOW_A.md` (Flow A sessions) or `NEXT_SESSION_FLOW_B.md` (Flow B sessions) only.
- Each flow updates exclusively its own document. Do not add Flow A content to
  `NEXT_SESSION_FLOW_B.md` or vice versa.
- **Branches and worktrees are not yet separated.** Flow A and Flow B currently share one branch
  (`ai-trader-implementation`) and one working tree — this split covers the operational documents only.

For the complete, consolidated project state (both flows, plus the frozen Research Lab), see
`PROJECT_STATE_v2.md`. For a genuinely new conversation with no prior context, start at
`RECONSTRUCTION_PROMPT.md`.
